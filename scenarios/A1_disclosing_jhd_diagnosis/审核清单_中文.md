## 一、需要核对出处的内容

### s16 Quarrell 等 2013，Managing juvenile Huntington's disease，Neurodegener Dis Manag 3(3):267-76
网址：https://pubmed.ncbi.nlm.nih.gov/24416077/ （全文：https://pmc.ncbi.nlm.nih.gov/articles/PMC3883192/ ）
- [ ] 青少年型 HD（JHD）定义为 20 岁或以前起病，约占全部 HD 的 5% — https://pmc.ncbi.nlm.nih.gov/articles/PMC3883192/
- [ ] JHD 早期常以运动迟缓、肌张力障碍为主，舞蹈样动作较少 — https://pmc.ncbi.nlm.nih.gov/articles/PMC3883192/
- [ ] 学习成绩下降、行为改变是常见的首发表现 — https://pmc.ncbi.nlm.nih.gov/articles/PMC3883192/
- [ ] 癫痫比成人型多见 — https://pmc.ncbi.nlm.nih.gov/articles/PMC3883192/
- [ ] CAG >60 通常是 JHD，但约一半 JHD 患者 CAG <60 — https://pmc.ncbi.nlm.nih.gov/articles/PMC3883192/
- [ ] 11–20 岁起病的 JHD 约 70–80% 由父亲遗传 — https://pmc.ncbi.nlm.nih.gov/articles/PMC3883192/
- [ ] 孩子可能先于父亲出现症状 — https://pmc.ncbi.nlm.nih.gov/articles/PMC3883192/
- [ ] 谈到父系遗传时要谨慎，家属可能因此更担心其他孩子 — https://pmc.ncbi.nlm.nih.gov/articles/PMC3883192/
- [ ] 不要暗示孩子的行为问题是父母教养不当造成的 — https://pmc.ncbi.nlm.nih.gov/articles/PMC3883192/
- [ ] 父母有时不希望在孩子面前谈 HD，这是 JHD 照护中公认的难题 — https://pmc.ncbi.nlm.nih.gov/articles/PMC3883192/
- [ ] 治疗以对症和支持为主，循证指南很少；需要多学科团队 — https://pmc.ncbi.nlm.nih.gov/articles/PMC3883192/

### s17 Cloud 等 2012，Seizures in juvenile HD，Mov Disord 27(14):1797-800
网址：https://pubmed.ncbi.nlm.nih.gov/23124580/
- [ ] 90 名 JHD 中 38% 有癫痫，起病越早越多见（A1 知识卡只用来支持"癫痫比成人型多见"）— https://pubmed.ncbi.nlm.nih.gov/23124580/

### s18 加拿大亨廷顿协会（HSC）《医生指南》第 3 版第 7 章 Juvenile Onset HD
网址：https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
- [ ] JHD 早期表现：腿僵硬、手脚笨拙、认知下降、行为改变、癫痫、口部运动改变 — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
- [ ] 孩子起病而父母看似未发病，可能是孩子先于父母起病、祖辈被误诊或未诊断等 — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
- [ ] 确诊能解释那些让孩子和家人困惑、害怕的症状，可能减轻压力 — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
- [ ] JHD 是慢性、进行性疾病，起病时无法预测病程 — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
- [ ] 团队：神经科、心理/精神科、物理治疗、作业治疗、言语治疗、家庭医生、牙医 — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
- [ ] ⚠ 指南建议神经科间隔 6–12 个月评估两次再做基因检测；我据此写了"8 个月前和 1 个月前各看一次"。请确认这个时间线合理 — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf

### 引导模式（guided.yaml）T1–T11
每轮三个选项：最好 / 一般 / 差。请看选项是否合理、家属反应是否真实、点评是否准确。
- [ ] T1（C1）最好："结果出来了。在讲之前，能说说你们觉得可能是什么吗？" 差（R1）：开口就说"HTT 基因一个拷贝有 71 个 CAG 重复" — https://pubmed.ncbi.nlm.nih.gov/10964998/
- [ ] T2（C2）最好："恐怕消息不是我们希望的。检测确认 Maya 患有亨廷顿病，是在年轻人中起病的那一型。" — https://pubmed.ncbi.nlm.nih.gov/10964998/
- [ ] T3（C3）最好：停顿后说"这很难接受，慢慢来" → Sarah 哭着说出 H3 — https://pubmed.ncbi.nlm.nih.gov/10964998/
- [ ] T4（C4）Sarah 问"她还能活多久？" 最好：说明无法对个人预测、会逐年缓慢变化，先征得同意再解释；差（R4）："通常 10 到 15 年" — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
- [ ] T5（C4）最好：用平实语言把运动、思维、情绪的变化和他们看到的症状联系起来，说明目前不能治愈但很多症状能处理 — https://pmc.ncbi.nlm.nih.gov/articles/PMC3883192/
- [ ] T6（C5）最好："HD 是遗传的，这可能也让你们想到自己的家族。Adam，你还好吗？" → Adam 说出 H1；差（R3）："病来自 Adam 那边，他也得去测" — https://pmc.ncbi.nlm.nih.gov/articles/PMC3883192/
- [ ] T7（C5）最好：没人能选择遗传什么，提供遗传咨询，检测由他决定 — https://pubmed.ncbi.nlm.nih.gov/22642570/
- [ ] T8（C6）最好：先问"Maya 知道这件事，您最担心的是什么？" 差（R6）："不告诉她是你们做父母的决定" — https://pmc.ncbi.nlm.nih.gov/articles/PMC3883192/
- [ ] T9（C6）最好：很多年轻人有了名字反而松一口气，一起计划、我可以在场、不必今天 → Sarah 同意几天后一起谈 — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
- [ ] T10（C7）Sarah 问"今天能测 Owen 吗？" 最好：理解担心，没有症状的孩子通常不测，转遗传科，出现变化会看；差（R5）："当然，走之前抽血" — https://cps.ca/en/documents/position/genetic-testing
- [ ] T11（C8）最好：两周内团队见 Maya、经同意联系学校、遗传咨询师来电、留电话和 HSC — https://www.huntingtonsociety.ca/
- [ ] ⚠ "两周内复诊"等具体时间是我写的，请按本地实际修改 — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
