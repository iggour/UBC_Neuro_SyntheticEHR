## 一、需要核对出处的内容

### s27 Chaganti 等 2017，What do we know about late onset HD?，J Huntingtons Dis 6(2):95-103
网址：https://pubmed.ncbi.nlm.nih.gov/28671137/ （全文：https://pmc.ncbi.nlm.nih.gov/articles/PMC5502838/ ）
- [ ] 晚发型 HD 一般指 60 岁以后起病；白种人 HD 队列中约占 4.4–11.5%（知识卡写"约 4–12%"） — https://pmc.ncbi.nlm.nih.gov/articles/PMC5502838/
- [ ] 因为觉得老年人不太可能患 HD，诊断容易被漏掉 — https://pmc.ncbi.nlm.nih.gov/articles/PMC5502838/
- [ ] 报告的晚发型病例大多 CAG ≤44 — https://pmc.ncbi.nlm.nih.gov/articles/PMC5502838/
- [ ] 舞蹈样动作最常见；步态不稳、跌倒突出；认知障碍可能是主要致残原因 — https://pmc.ncbi.nlm.nih.gov/articles/PMC5502838/
- [ ] 进展可能较慢 — https://pmc.ncbi.nlm.nih.gov/articles/PMC5502838/
- [ ] 这可能是家族中第一个 HD 诊断，需要仔细的遗传咨询 — https://pmc.ncbi.nlm.nih.gov/articles/PMC5502838/

### s28 Langbehn 等 2004，CAG 长度与起病年龄、外显率模型，Clin Genet 65(4):267-77
网址：https://pubmed.ncbi.nlm.nih.gov/15025718/
- [ ] 外显率取决于 CAG 长度和年龄；36–39 区间的估计不确定（知识卡只用它支持"不确定"，没有引用具体数字） — https://pubmed.ncbi.nlm.nih.gov/15025718/

### s29 Kay 等 2016，外显不全等位基因在普通人群中很常见，Neurology 87(3):282-8
网址：https://pubmed.ncbi.nlm.nih.gov/27335115/ （全文：https://pmc.ncbi.nlm.nih.gov/articles/PMC4955276/ ）
- [ ] 普通人群中约每 400 人有 1 人 CAG ≥36，很多人一生都不会被诊断 — https://pmc.ncbi.nlm.nih.gov/articles/PMC4955276/
- [ ] ⚠ 这篇研究里 39 的人群频率是 0%，说的主要是 36–38。用它来支持 Ruth 孩子的情况是否合适？ — https://pmc.ncbi.nlm.nih.gov/articles/PMC4955276/

### s30 Almqvist 等 2001，BC 省新诊断 HD 中四分之一无家族史，Clin Genet 60(3):198-205
网址：https://pubmed.ncbi.nlm.nih.gov/11595021/
- [ ] BC 省 1993–2000 年新诊断患者中约 24% 没有 HD 家族史 — https://pubmed.ncbi.nlm.nih.gov/11595021/

### s35 HSC《医生指南》第 3 版第 2 章（遗传咨询与检测）
网址：https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
- [ ] 约 5% 的 HD 患者不知道有家族史；原因包括父母早逝、收养、亲子关系不符、父母高正常值扩增成新突变 — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
- [ ] 看起来像 HD 但没有家族史时，应常规做诊断性基因检测 — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
- [ ] 基因检测只确定有没有扩增；判断症状是否属于 HD 的是临床医生 — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
- [ ] 36–39 是"外显不全"区间：不是每个人都会在正常寿命内发病；≥40 在正常寿命内一定发病 — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
- [ ] 向这类人做咨询要谨慎，避免高估风险；需要熟悉 HD 遗传学的遗传咨询师 — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
- [ ] ⚠ 知识卡写"重复数在传代时可能改变，经父亲传递时变化更大"。指南原文讲的是新突变和青少年型通常来自父亲，这样概括可以吗？ — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
- [ ] 第 8 章：要趁早做规划，因为后期患者难以表达复杂的意愿 — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf

### 引导模式（guided.yaml）T1–T13
- [ ] T1（C1）最好：先问预期 → "我以为什么事都没有"；差（R1）：开口就报 17 和 39 — https://pubmed.ncbi.nlm.nih.gov/10964998/

- [ ] T3（C2）最好："检测结果加上你的这些变化，说明你患有亨廷顿病"；差（R2）："在你这个年龄，这种结果有时会出错" — https://pmc.ncbi.nlm.nih.gov/articles/PMC5502838/
- [ ] T4（C2）最好：停顿，承认她的震惊 — https://pubmed.ncbi.nlm.nih.gov/10964998/
- [ ] T5（C3）"我都 68 了怎么会是遗传的？" 最好：基因从出生就有，但可能多年后才表现，再问父母 → 说出 H1 — https://pmc.ncbi.nlm.nih.gov/articles/PMC5502838/
- [ ] T6（C3）最好：无法确定，但父母的 HD 常被漏诊或被叫作别的病；这种"家族第一例"并不少见 — https://pubmed.ncbi.nlm.nih.gov/11595021/
- [ ] T7（C4）最好：HD 影响运动、思维、情绪；晚年起病常进展较慢；不能治愈但有很多办法 — https://pmc.ncbi.nlm.nih.gov/articles/PMC5502838/
- [ ] T8（C5）最好：每个孩子有一半机会；39 不一定发病；数字可能在传代时改变；转遗传咨询 → 说出 H2；差（R3）："39 的人几乎都没事"；一般（R1）：报外显率数字 — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
- [ ] ⚠ T8 最好选项说"在 39，不是每个携带者都会在一生中发病"。对于孩子，如果他们遗传的是 39 也是这样，但重复数可能改变。表达是否准确、是否太多？ — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
- [ ] T9（C6）最好：何时、如何告诉子女由她决定，可以请遗传咨询师帮忙，检测与否由子女自己决定；差（R4）："这周就得告诉他们，都去测" — https://pubmed.ncbi.nlm.nih.gov/22642570/
- [ ] T10（C6）George 问孙辈要不要测。最好：没有症状的孩子不测，成年后自己决定，Anna 测不测是 Anna 的决定；差（R5） — https://cps.ca/en/documents/position/genetic-testing
- [ ] T11（C7）最好：提到加拿大法律保护，保险公司或雇主不能要求做检测或提供结果 — https://laws-lois.justice.gc.ca/eng/acts/g-2.5/FullText.html
- [ ] T12（C8）最好：分别问 George 和 Ruth → George 说出 H3，Ruth 说出 H4 — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
- [ ] T13（C8）最好：4 周后带护士和遗传咨询师复诊，提到以后要谈驾驶和提前规划；差："今天就停止开车" — https://hsc.huntingtonsociety.ca/public/resources/physicians-guide.pdf
