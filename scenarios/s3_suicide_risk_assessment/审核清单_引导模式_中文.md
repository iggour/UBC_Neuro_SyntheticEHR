# 场景 3 引导模式（guided.yaml）中文审核清单

引导模式：每一轮给医生三个回应，一个最好（best）、一个一般（partial）、一个踩红旗（poor）。病人的回答和导师点评都是预先写好的，不用 AI。只有第一次就选对，这一轮的检查点才算完成。
没有新增来源。导师点评沿用 checkpoints.yaml 里已经核对过的说法（s8、s10–s15）。请主要从临床角度判断：选项是否合理、病人反应是否真实、点评是否准确。
逐条核对，没问题就把 [ ] 改成 [x]，有问题直接在下面写批注。

开场：
Teresa："我不知道 Luis 为什么要小题大做。我没事。"
Luis："她不是没事。上周她说——"
Teresa："Luis。"

---

## T1（C2 共情、不争辩）
- 一般：「既然你没事，那我们先看看你的不自主运动吧。」→ Teresa："行。你要怎样都行。" 点评：直接跳过会错过 Luis 担心的原因，先回应她的感受。
- 最好：「Teresa，我想听你自己说。听起来今天早上挺让你烦的。」→ "是啊。大家说起我都当我不在场。" 点评：直接和她说话，说出她的烦躁，没有争辩。
- 红旗 R5：「Luis，她上周说了什么？」→ "我自己会说，你知道的。" 点评：当着她的面问 Luis，会加重她的失控感。
- [ ] 合理

## T2（C1 单独谈话）
- 红旗 R5：「Luis，你能说说家里最近发生了什么吗？」→（看向别处）"说吧，你告诉他们。" 点评：她刚说过大家总替她说话，要继续和她本人交谈。
- 一般：「Luis 在这里，我们聊你的感受可以吗？」→（看了一眼 Luis）"可以。" 点评：问是好意，但很少有人会当着伴侣说"不行"。应把单独谈话作为常规安排提出。
- 最好：「Luis，能不能请你给我们几分钟？之后我再请你回来。」→ Luis："当然，我就在外面。" Teresa（小声）："谢谢。" 点评：单独谈话往往让人能说出自杀想法。
- [ ] 合理

## T3（C3 情绪）
- 最好：「最近一两个月你的情绪怎么样？睡眠、平时喜欢做的事呢？」→ "大部分时候都很低落。睡不着。夏天以后就没碰过花园了。"
- 红旗 R2：「HD 患者情绪低落挺正常的，对吧？」→ "别人都这么说。" 点评：说"正常"会让对话就此打住。HD 中的情绪低落是风险因素，需要深入了解。
- 一般：「你抑郁吗？」→ "不知道。可能吧。换你你不会吗？" 点评：封闭式问题只能得到简短回答。
- [ ] 合理

## T4（C3 近期变化 → 引出 H1 自责）
- 一般：「家里出什么事了吗？」→ "这几个月挺难的。"
- 差：「我们先看看你的用药清单。」→ "随你。" 点评：她刚说情绪低落，先别转到用药。
- 最好：「最近有什么变化，或者你心里一直在想什么？」→ "Leah 拿到结果了。她有。是我把这个传给了我女儿。我看着我父亲经历过，现在她也会。"
- [ ] 合理

## T5（C2 共情）
- 差：「没必要内疚，你当时不可能知道。」→ "你说得倒轻巧。" 点评：告诉她不该有什么感受，听起来像在否定她。
- 最好：「这是很沉重的负担。这不是你能选择的。」→（哭）"我知道。可到了晚上就不是这种感觉。" 点评：注意"到了晚上"，这是继续追问的线索。
- 一般：「Leah 是成年人了，我相信她能应对。」→ "你不了解她。" 点评：安慰 Leah 会把焦点从 Teresa 身上移开。
- [ ] 合理

## T6（C4 直接询问自杀想法 → 引出 H2）
- 红旗 R1：「你没想做什么傻事吧？」→ "没有。我说了我没事。"
- 一般：「你有没有一些消极的想法？」→ "有时候觉得很灰暗。谁不是呢？" 点评：含糊的问法只会得到含糊的回答。
- 最好：「Luis 说你跟他讲过，没有你家里会过得更好。你有过结束自己生命的想法吗？」→（长时间停顿）"有。最近两三周。多在夜里。我从没做过什么。" 点评：直接询问不会增加自杀想法。
- [ ] 合理

## T7（C5 计划、准备、手段 → 引出 H3）
- 一般：「这些想法多久出现一次？」→ "最近几乎每晚。" 点评：有用，但还需要了解计划、准备和手段。
- 最好：「谢谢你告诉我。你有没有做过什么计划或准备，家里有没有你想过会用的东西？」→ "我在床头抽屉里留了一些以前的安眠药。以防万一。我没吃过。Luis 不知道。"
- 红旗 R3：「你跟我说的任何话都只在我们之间。」→ "……好吧。" 点评：不能这样承诺，要如实说明为了她的安全，有些信息可能需要分享。
- [ ] 合理
- [ ] ⚠ 引导模式的病人台词是公开写在网页里的，包括"床头抽屉里的安眠药"（没有种类和数量）。可以接受吗？

## T8（C6 药物和抑郁）
Teresa 先问："是不是那些药让我变成这样的？治动作的那个？"
- 差：「不太可能。」→ "那就是我自己的问题了。" 点评：丁苯那嗪有抑郁和自杀倾向的黑框警告。
- 一般：「那就先停掉吧。」→ "就这样停？" 点评：怀疑药物是对的，但调整应与处方医生一起计划。
- 最好：「这个药有些人吃了会影响情绪，我今天会和开药的医生一起评估。像你这样的情绪低落也是可以治疗的。」→ "从来没人跟我说过。知道不只是我自己的问题，我好受一点。"
- [ ] 合理
- [ ] ⚠ "一般"选项是"先停掉"。临床上把它标为"一般"而不是"红旗"合适吗？

## T9（C7 安全计划和手段）
- 差：「我会让 Luis 把家里危险的东西都收走。」→ "那我在自己家里成了囚犯？" 点评：强加的计划会引起抗拒。
- 最好：「我们一起写一个计划，想法出现时可以照着做。你同意让 Luis 把安眠药拿走、帮你保管药物吗？」→ "如果你跟他解释……可以。我不想让他成为发现我的那个人。"
- 一般：「你能答应我不做傻事吗？」→ "我答应。" 点评：承诺不等于安全计划。
- [ ] 合理

## T10（C8 当天紧急评估）
- 一般：「我给你转精神科，他们会给你寄预约。」→ "好吧。" 点评：常规转诊可能要等几周，有准备行为的主动自杀想法需要当天评估。
- 红旗 R4：「先看看情况，三个月后再见。」→ "三个月。行。"
- 最好：「我很担心你，希望你今天就去见精神健康团队，Luis 可以陪你。」→ "今天？我又没疯。……如果 Luis 陪我，我就去。" 点评：同时给出 9-8-8。
- [ ] 合理
- [ ] ⚠ 当天紧急评估的说法与你们当地流程一致吗？

## T11（C9 照护者）
（Luis 回到房间。经 Teresa 同意，你向他说明计划。）
- 一般：「Luis，从现在起你得看着她。」→ "我一直都在看着。时时刻刻。" 点评：这样只是加重他的负担，没有问他自己怎么样。
- 差：「今天就到这儿，有问题吗？」→ "没有……大概没有吧。"
- 最好：「Luis，这一切你是怎么应对过来的？」→ "说实话？我筋疲力尽。睡不着，也不敢留她一个人。我没告诉孩子们，他们自己的事已经够多了。"
- [ ] 合理

结尾提示：离开前给出危机热线 9-8-8（随时可打电话或发短信）、当天去见精神健康团队、尽早随访。
